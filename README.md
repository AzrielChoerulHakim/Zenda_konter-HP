# Zenda Konter HP

Website storefront untuk **Zenda Konter HP**, dengan fokus produk smartphone Samsung.

## Fitur
- Responsive / mobile-first
- Hero premium
- Katalog Samsung berbasis kategori
- Filter Flagship / Foldable / Value
- Section keunggulan toko
- CTA konsultasi
- Animasi ringan tanpa framework
- Siap untuk GitHub Pages

## Struktur
- `index.html` — struktur utama halaman
- `styles.css` — seluruh desain dan responsive styling
- `script.js` — katalog, filter, menu mobile, animasi
- `.nojekyll` — kompatibilitas GitHub Pages

## Data yang masih perlu diisi
Sebelum website digunakan sebagai toko live, tambahkan:
1. Nomor WhatsApp Zenda
2. Alamat toko
3. Jam operasional
4. Daftar model Samsung yang benar-benar tersedia
5. Harga / promo jika ingin ditampilkan
6. Instagram atau marketplace jika ada

Katalog saat ini sengaja ditampilkan per keluarga produk agar website tidak mengklaim stok atau harga yang belum diberikan.
